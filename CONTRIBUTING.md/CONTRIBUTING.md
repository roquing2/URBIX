Contributing to URBIX

Thank you for your interest in contributing to URBIX.

URBIX is an independent digital currency project focused on open development, transparency, security and global community participation.

We welcome developers, researchers, translators, testers and documentation contributors.

1. Ways to Contribute

You can contribute by:

- Improving technical documentation.
- Reviewing existing code.
- Reporting bugs.
- Researching blockchain architecture.
- Evaluating consensus mechanisms.
- Improving security practices.
- Translating project materials.
- Proposing technical improvements.

2. Before Contributing

Please read:

- README.md
- ROADMAP.md
- WHITEPAPER.md
- SECURITY.md

Understand the current project status before proposing changes.

The independent URBIX blockchain is not yet operational.

3. Reporting Issues

When reporting an issue, provide:

- A clear title.
- A description of the problem.
- Steps to reproduce it, if applicable.
- Expected behavior.
- Actual behavior.
- Relevant technical information.

Do not include passwords, private keys, recovery phrases or sensitive personal information.

4. Proposing Changes

For code or documentation contributions:

1. Fork the public repository.
2. Create a separate branch.
3. Make focused changes.
4. Explain what was changed and why.
5. Submit a pull request for review.

All contributions are subject to review.

5. Development Standards

Contributions should prioritize:

- Security.
- Readability.
- Maintainability.
- Transparency.
- Accurate technical documentation.
- Compatibility with the project's documented architecture.

Do not introduce undocumented financial promises or misleading technical claims.

6. Security Contributions

Potential vulnerabilities should be reported privately and responsibly.

Please follow the instructions in SECURITY.md.

Do not publish exploit details that could expose users to harm.

7. Community Conduct

All participants are expected to:

- Communicate respectfully.
- Welcome constructive criticism.
- Avoid harassment and discrimination.
- Support transparent decision-making.
- Respect independent technical review.

8. Review and Acceptance

Submitting a contribution does not guarantee acceptance.

Maintainers may request modifications, clarification or additional testing.

Contribution licensing and governance procedures will be documented separately before formal adoption.

9. Project Status

URBIX currently operates as a BEP-20 token on BNB Smart Chain.

An independent blockchain, native coin, standalone wallet and validator network remain future development objectives.

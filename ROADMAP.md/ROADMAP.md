URBIX Development Roadmap

Project: URBIX — Independent Digital Currency
Status: Early Development
Last updated: November 2026

Vision

Build an independent digital currency project through open-source development, transparent technology, international community participation and progressive decentralization.

The long-term objective is to research and potentially develop an independent blockchain. This blockchain does not exist yet.

Phase 1 — Foundation and Transparency

Status: In progress

- [x] Deploy the URBIX BEP-20 token on BNB Smart Chain.
- [x] Publish and verify the smart contract source code.
- [x] Create the public GitHub repository.
- [x] Publish the initial project documentation.
- [ ] Complete technical documentation.
- [ ] Establish public communication channels.
- [ ] Publish regular development updates.
- [ ] Document token distribution and liquidity risks.

Phase 2 — Open-Source Community

Status: Planned

- [ ] Establish contribution guidelines.
- [ ] Organize community discussions.
- [ ] Invite independent developers and reviewers.
- [ ] Create a public issue-tracking process.
- [ ] Publish technical proposals and decisions.
- [ ] Build an international community.

Phase 3 — Blockchain Research

Status: Planned

Research the technical requirements for an independent URBIX blockchain.

Areas of research:

- Blockchain architecture.
- Consensus mechanisms.
- Network security.
- Peer-to-peer communication.
- Transaction validation.
- Node infrastructure.
- Wallet architecture.
- Block explorer.
- Network scalability.

The consensus mechanism has not yet been selected. Proof of Work and Proof of Stake are among the models to evaluate.

Phase 4 — Experimental Network

Status: Planned

Subject to successful research and available resources:

- [ ] Develop an experimental blockchain prototype.
- [ ] Create a test network.
- [ ] Implement basic transaction processing.
- [ ] Develop independent node software.
- [ ] Test network synchronization.
- [ ] Test wallet connectivity.
- [ ] Conduct performance and security testing.

The experimental network will not represent a production-ready financial network.

Phase 5 — Security and Decentralization

Status: Planned

- [ ] Request independent security reviews.
- [ ] Conduct professional audits before production deployment.
- [ ] Develop transparent validator or miner participation rules.
- [ ] Define governance procedures.
- [ ] Document network upgrade procedures.
- [ ] Establish incident response procedures.

Phase 6 — Native Blockchain Evaluation

Status: Future consideration

- Evaluate the feasibility of a native URBIX blockchain.
- Define the native coin's technical specifications.
- Evaluate supply and distribution policies.
- Develop a migration proposal if appropriate.
- Publish migration rules before implementation.
- Obtain appropriate legal review.

There is currently no guarantee that existing URBX tokens will be converted into a future native coin.

Phase 7 — Mainnet Consideration

Status: Future consideration

A production network should only be considered after:

- Successful public testnet operation.
- Independent security audits.
- Documented decentralization.
- Stable node infrastructure.
- Tested wallet and explorer software.
- Transparent governance.
- Legal and regulatory review.

Development Principles

1. Transparency before promotion.
2. Open-source development.
3. Security before deployment.
4. Community participation.
5. Independent technical review.
6. Responsible decentralization.
7. No promises of financial returns.

Current Project Status

URBIX currently exists as a BEP-20 token on BNB Smart Chain.

Its independent blockchain, native coin, official standalone wallet, validator network and dedicated payment infrastructure have not yet been developed.

This roadmap describes objectives, not guaranteed delivery dates or outcomes.

Contributing

Developers and community members interested in URBIX may participate through technical discussions, documentation improvements, research and code contributions.

All contributions should prioritize transparency, security and responsible development.
